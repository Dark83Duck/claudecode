# 교과평가 누락 점검표

초등학교 교과평가 계획서를 2022 개정 교육과정의 학년·교과별 평가영역과 비교하여,
1학기와 2학기를 통틀어 한 번도 평가되지 않은(누락된) 영역을 찾아주는 웹 기반 도구입니다.
서버나 설치 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 사용 방법

1. **① 영역 데이터** 탭에서 학년군·교과별 평가영역을 확인하고, 학교 교육과정과 다르면
   영역을 추가/삭제하거나 새 교과를 등록합니다. 기본 제공 데이터는 참고용이며, 특히
   통합교과·실과·음악 영역은 학교별 재구성 폭이 커서 **반드시 확인**이 필요합니다.
2. **② 평가계획 입력** 탭에서 학년·교과·학기·평가영역을 골라 한 건씩 추가하거나,
   `학년/교과/학기/평가영역` 열이 포함된 엑셀(.xlsx/.xls)·CSV 파일을 업로드해 한 번에
   불러옵니다.
3. **③ 누락 점검 결과** 탭에서 학년·교과별로 1·2학기 중 한 번도 실시되지 않은 평가영역을
   확인합니다. 등록된 영역명과 일치하지 않는 입력은 "확인이 필요한 항목"으로 별도 표시됩니다.

입력한 데이터는 브라우저의 로컬 저장소(localStorage)에만 저장되며, 다른 기기나 사용자와
공유되지 않습니다.

## 기본 제공 교육과정 데이터의 한계

내장된 교과별 평가영역은 2022 개정 교육과정 각론을 참고해 작성한 것이지만, 학교 교육과정
편성·재구성에 따라 실제 운영과 다를 수 있습니다. 반드시 학교의 교육과정 문서를 기준으로
① 영역 데이터 탭에서 검토·수정한 뒤 사용하세요.
